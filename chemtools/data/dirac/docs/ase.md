# ASE-DIRAC

DIRAC has an interface to the ASE (Atomistic Simulation Environment)
workflow software that can be installed following the instructions in
the <span class="title-ref">ase_dirac</span> folder. After installation
you can use this to build workflows in which DIRAC is run with automatic
generation of the required input. A jupyter-notebook tutorial to
demonstrate a simple workflow can be found in the folder
<span class="title-ref">demo_notebooks</span>.
